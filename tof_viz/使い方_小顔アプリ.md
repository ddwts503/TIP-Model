# 小顔比較アプリ 使い方(完成版)

ベッドに寝た人を真上から撮った 3D ToF データ(.dat)で、**ビフォー・アフターの
小顔(顔幅・奥行き)を比べる**アプリです。すべてブラウザ(Chrome)で動きます。

---

## 起動のしかた

**デスクトップの「小顔比較アプリ」をダブルクリックするだけ。**

- 起動時に自動で最新版に更新 → SSDの計測データを自動で読み込み → ブラウザが開く
- 初回だけ:右クリック →「開く」(Macの安全確認)
- 終了:黒いウインドウで **Control + C**

> アイコンが無い場合(初回):ターミナルで
> `cp ~/TIP-Model/tof_viz/小顔比較アプリ.command ~/Desktop/`

---

## 画面の操作(すべてスライダー。クリック不要)

1. **前のコマ / 後のコマ** スライダー
   → 比べたい2つの時点(before / after)のコマを選ぶ。顔が正面でまっすぐ写った
     コマ同士を選ぶと正確。

2. **before 顔の位置(左右 / 上下)** スライダー
   → 左の画像の黒い○(顔の範囲)を before の顔に重ねる。

3. **after 顔の位置(左右 / 上下)** スライダー
   → 右の画像の○を after の顔に重ねる。

4. **顔の範囲(半径)** スライダー
   → ○の大きさ。**髪・肩が入らず、顔だけが入る大きさ**に。

5. **☑ 2つの顔を自動で重ねて比較**
   → before/after の傾き・向き・位置を自動で合わせる(ICP)。基本ONのまま。

6. **計測する高さ z'** スライダー(参考断面の高さ)

→ 下にスクロールすると **表** と **判定** が出ます。

---

## 結果の見かた(◎が重要)

| 項目 | 意味 | 小顔の見かた |
|------|------|------------|
| **◎ 顔幅(左右)** | 顔の横幅 [mm] | **減っていれば小顔** |
| **◎ 奥行き(突出・高さ)** | 顔の出っぱり [mm] | むくみ/立体感の指標 |
| 顔の長さ(頭足) | 縦の長さ [mm] | 参考 |
| 顔の体積 | 顔の盛り上がりの量 [cm³] | 参考 |
| (参考)断面の面積 | [cm²] | ※立体化で増えるので参考のみ |

- **判定**:顔幅と奥行き(と体積)の多くが減っていれば「✅ 小顔になっています」。
- 断面積は「扁平→立体的」になるだけで増えるため、**主役は顔幅と奥行き**。

---

## 正確に比べるコツ

- **before と after は、できるだけ同じ向き・同じ姿勢のコマ**を選ぶ。
- **○は毎回、顔だけをちょうど囲むように**合わせる(髪・首・肩を除く)。
- 本当の「治療前後」を比べるなら、**別々に撮った2つの録画**を使う
  (同じ録画の別コマは「動いただけ」なので比較になりません)。
- 「☑自動で重ねる」をONにして、2つの顔の向きをそろえる。

---

## 2つの録画(別の日)を比べるには

ターミナルで(末尾にそれぞれのファイルをドラッグ):
```
python3 -m tof_viz --mode compare --after <後の.dat> <前の.dat>
```
コマは画面のスライダーで選べます。
