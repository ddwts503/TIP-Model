# ベッド基準・矢状面合わせの調整説明書

ベッドを基準面(XY)、高さを Z にして、**矢状面(左右を分ける面)を体の中心**に
合わせるための調整方法です。スライダーは使わず、**数字を変えて再実行 → 画像を見る**を
くり返して合わせます(窓が固まらない確実な方法)。

---

## 基本コマンド

```bash
python3 -m tof_viz --mode bed --frame 255 \
  --save-csv ~/Desktop/before.csv --save ~/Desktop/before_bed.png \
  /Volumes/SSD-PSTU3A/20260608-132118/センサー1/センサー1_20260608-132118.dat
```

実行すると:
- ベッドが水平の基準面(Z=高さ)になる
- 体の対称軸を自動で見つけて、**矢状面を体の中心(x'=0)に自動整列**
- `before_bed.png` が自動で開く
- `before.csv`(整列した点群)が保存される

---

## 画像の見方

**左 = 上から見た図(TOP view)**
- 体を真上から見たもの。色 = ベッドからの高さ
- **赤い縦線 = 矢状面(x'=0)**。これが**体の真ん中(鼻すじ・背骨)を通っていれば成功**

**右 = 横から見た図(SIDE view)**
- 赤い水平線 = ベッド(z'=0)。体がその上に盛り上がって見える

→ まず**左の図で、赤い縦線が体の中心を通っているか**を確認します。

---

## 調整の3つのつまみ

赤い中線が体の中心からズレていたら、コマンドに次を足して再実行します。

| つまみ | 意味 | 使いどき |
|--------|------|---------|
| `--yaw 5` | 水平に5°回す | 中線が体に対して**斜め**のとき(まっすぐにする) |
| `--dx 10` | 左右に10mm動かす | 中線が体の中心から**左右にズレ**ているとき |
| `--dy 10` | 頭足方向に10mm動かす | 前後(頭〜足方向)の位置を動かしたいとき |

### 向きの決め方(迷ったら反対も試す)
- **中線より体が右にある** → `--dx` を**大きく(プラス)**:例 `--dx 20`
- **中線より体が左にある** → `--dx` を**マイナス**:例 `--dx=-20`(マイナスは `=` でつなぐ)
- **体が傾いている** → `--yaw 5` を試す。逆に傾いたら `--yaw=-5` に
- 数字の大きさ:大きくズレてるほど大きい値(例 30)、ほぼ合ってるなら小さい値(例 3)

### 調整つきコマンドの例
```bash
python3 -m tof_viz --mode bed --frame 255 --yaw 5 --dx 15 --dy 0 \
  --save-csv ~/Desktop/before.csv --save ~/Desktop/before_bed.png \
  /Volumes/SSD-PSTU3A/20260608-132118/センサー1/センサー1_20260608-132118.dat
```

これを「数字を変えて再実行 → 画像で赤線を確認」とくり返し、**赤線が体の中心を
まっすぐ通る**まで合わせます。

### 完全に手動で合わせたいとき
自動の中心合わせを切るには `--no-center` を足します(その上で `--yaw/--dx/--dy`)。

## 合ったら:輪切りと前後比較

矢状面が中心に合った `before.csv` を使って:

```bash
# 高さごとの輪切り(ベッドに平行)
python3 -m tof_viz ~/Desktop/before.csv --mode grid --axis z --n 9 --save ~/Desktop/slices.png

# 矢状面の断面(左右の中心で切った縦断面)
python3 -m tof_viz ~/Desktop/before.csv --mode grid --axis x --n 9 --save ~/Desktop/sagittal.png

# 断面の長さ・面積を計測(例: 高さ40mmの層)
python3 -m tof_viz ~/Desktop/before.csv --mode measure --axis z --pos 40 --thickness 5 --save ~/Desktop/measure.png
```

「後」のデータも同じ手順で `after.csv` を作り、前後比較:
```bash
python3 -m tof_viz ~/Desktop/before.csv --mode measure --axis z --pos 40 \
  --compare ~/Desktop/after.csv --save ~/Desktop/hikaku.png
```

---

## 用語のまとめ
- **x'(左右)= 矢状面の法線**。`--axis x` で切ると矢状面スライス
- **y'(頭足)= 前頭面(背中の面)の法線**。`--axis y` で前頭面スライス
- **z'(高さ)= 横断面の法線**。`--axis z` でベッドに平行な横断面スライス
- 赤線(上面図)= 矢状面 x'=0、赤線(側面図)= ベッド z'=0
